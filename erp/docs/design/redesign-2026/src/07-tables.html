11.1 DataTable specification

AspectSpecification
Row densitycompact 32 · default 40 · touch 48. Cell padding-inline 10px; 12px on the first and last column. Wrapping allowed only in a designated "primary" column (max 2 lines); everything else truncates with a tooltip.
Header32px, sunken, 12/500 fg-muted, 1px border top and bottom. Labels include units: الكمية (كغ), القيمة (ر.س), so cells hold bare numbers.
StickyHeader sticky within the table's scroll container (not the window). Pinned columns: selection checkbox + identifier column at the start side; optional pinned action column at the end. Pinned edge gets a 1px border shadow-rule when content scrolls under it.
Column visibility and orderالعرض › الأعمدة: checklist with drag handles; "reset to default". Each table declares defaultVisible, hideable, and a priority 1–3 used for responsive hiding.
ResizingDrag handle on the header's end edge (8px hit area), min 64px, double-click to fit. Widths persisted per user per view.
SortingClick header: asc → desc → none. Indicator arrow after the label; aria-sort on th. Shift-click adds secondary sort. Every table defines its default sort (e.g. orders: delivery date asc; ledger: date desc).
FiltersChips in the toolbar (§8.7). Types: enum (multi), person, date range with presets, number range, boolean, text contains. Server-side for anything paginated.
Saved viewsTabs above the toolbar. A view = filters + sort + columns + density + group-by. Personal by default; "share with team" requires a permission. Modified view shows a dot and حفظ · تجاهل.
SearchToolbar search matches the table's declared text fields with Arabic normalisation; highlights matches in cells.
SelectionCheckbox column; Shift-click range; header checkbox selects the page and then offers تحديد كل النتائج (48). Selected rows: selected bg. Selection survives pagination within the same filter.
Bulk actionsFloating bar (pattern 07). Each action declares eligibility; ineligible rows are counted (2 من 5 لا يمكن نقلها: بانتظار الاعتماد). Results reported per row.
Row actionsPrimary row action as a visible small button when the row's state has a clear next step (اعتماد, تأكيد الاستلام); otherwise ⋯ menu, visible on hover/focus and always on touch. Row click opens the drawer; Ctrl/⌘-click or middle-click opens the full page.
Inline editingOnly for single-value fields with no side-effects (owner, due date, notes, reorder point). Click or E → field in place → Enter saves, Esc cancels; optimistic with rollback and an inline error. Quantities that move stock or money are never inline-edited.
Pagination vs infinitePagination (25/50/100) for transactional lists people refer back to (orders, bills, ledger). Virtualised infinite scroll for logs and movements (audit, stock movements, activity) with a "jump to date" control. Never infinite scroll above a footer with totals.
Summary rowSticky footer row for additive columns with one unit. Label states scope. Totals computed server-side over the full filtered set, not the page.
Status cellsStatusTag + optional RiskFlag; two status dimensions get two columns.
NumbersEnd-aligned (left in RTL), tabular, fixed decimals per column (kg 2, SAR 2 in transactional tables, 0 in summaries), thousands separators, negatives as −1,250.00 in danger colour with the minus sign (never parentheses alone).
CurrencyUnit in the header; cell holds the number. When a table mixes currencies, a currency code column (SAR, USD) precedes the amount.
DatesLists: 8 أكتوبر (year only if not current); tooltip with full datetime and timezone. Relative time (قبل 3 ساعات) only in activity and audit, with absolute on hover.
Hover and focusRow hover bg-hover; keyboard focus ring on the row (2px inset brand) with J/K/arrow navigation; row actions revealed on focus too.
Empty / loading / errorHeader and toolbar always render. Loading: 8 skeleton rows. Empty and no-results per pattern 28. Partial failure: rows that loaded stay, an inline alert names what failed.
ExportExports the current view (filters, columns) as XLSX/CSV with Arabic headers and UTF-8 BOM; permission-gated.

11.3 Responsive table behaviour

  • ≥1280: all priority ≤ 3 columns; sidebar expanded.
  • 1024–1279 (floor tablets): hide priority-3 columns, keep pinned identifier, horizontal scroll for the rest, touch density on coarse pointers. Do not convert to cards; replaces .stack-table.
  • 640–1023: priority 1 and 2 only; row action column stays pinned at the end.
  • <640: list rows: line 1 identifier + status tag, line 2 the two most important values, trailing amount; tap opens the record as a full-screen sheet. Filters in a bottom sheet; bulk select via long-press.
